# 社交媒体趋势分析工具 - 完整项目文档

## 📋 项目概述

### 产品定位

**社交媒体趋势分析工具（IdeaEden）**是一个专为科技创业者和中小企业设计的AI驱动分析平台。通过实时抓取和分析社交媒体数据，提供企业级洞察和商业智能，帮助用户快速验证产品想法、监控竞争对手、发现市场机会。

### 核心价值主张
> **"企业级洞察，初创公司价格"**
> 
> 提供Brandwatch 80%功能，仅需20%价格；一键分析vs复杂仪表板设置

### 目标用户
- **科技创业者**：25-40岁，Pre-seed到Series A阶段，需要快速市场验证
- **独立创业者**：验证产品idea，分析市场趋势，竞争对手监控
- **小企业团队**：品牌监控，市场机会发现，营销策略制定
- **个人创作者**：内容创作方向，市场洞察报告

# 后端实现：分层分析逻辑
def analyze_trends_by_tier(keywords: List[str], user: User) -> TrendAnalysisResult:
    tier = user.subscription_tier
    
    if tier == SubscriptionTier.FREE:
        return execute_basic_analysis(keywords)  # 基础分析包
    elif tier == SubscriptionTier.STARTER:
        return execute_standard_analysis(keywords)  # 标准分析包
    elif tier == SubscriptionTier.PRO:
