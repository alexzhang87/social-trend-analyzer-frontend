## 🔄 Navigation Flow

### New User Journey
1. **Landing Page** (`/`) → Learn about platform
2. **Sign Up** → Create account
3. **Dashboard** (`/dashboard`) → Get oriented
4. **Analysis** (`/analysis`) → Start first analysis
5. **Pricing** (`/pricing`) → Upgrade if needed

### Regular User Workflow
1. **Dashboard** (`/dashboard`) → Check recent activity
2. **Analysis** (`/analysis`) → Run new analysis
3. **Analysis Detail** (`/analysis/:id`) → Review results
4. **Reports** (`/reports`) → Generate professional reports
5. **User Center** (`/user-center`) → Manage account

### Entrepreneur Workflow
1. **Entrepreneur Dashboard** (`/entrepreneur`) → Business overview
2. **PMF Validation** (`/pmf-validation`) → Validate product-market fit
3. **Founder Toolkit** (`/founder-toolkit`) → Use business tools
4. **Workspace** (`/workspace`) → Manage projects
5. **Reports** (`/reports`) → Create investor presentations

## 🎯 Quick Actions

### From Any Page
- **Search**: Use global search in header
- **Profile**: Click user avatar for quick access
- **Help**: Access support via chat or help center
- **Home**: Click logo to return to landing page

### Keyboard Shortcuts
- `Ctrl + /`: Open search
- `Ctrl + N`: New analysis (where available)
- `Ctrl + S`: Save current work
- `Esc`: Close modals

## 📱 Mobile Navigation

All pages are mobile-responsive with:
- Hamburger menu for navigation
- Touch-friendly buttons and forms
- Optimized layouts for small screens
- Swipe gestures where appropriate

## 🔍 Search & Discovery

### Global Search Features
- Search across all your analyses
- Filter by date, type, or status
- Quick access to recent items
- Suggested searches based on history

### Page-Specific Filters
- **Analysis Page**: Filter by keywords, date range, data sources
- **Dashboard**: Sort by date, status, or relevance
- **Reports**: Filter by type, creation date, or sharing status
