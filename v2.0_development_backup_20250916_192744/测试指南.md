# 社交趋势分析系统 - 测试指南

## 📧 邮箱验证逻辑说明

### 验证流程
1. **注册验证**：用户注册时需要邮箱验证码验证
2. **验证码生成**：6位数字验证码，有效期10分钟
3. **存储方式**：验证码存储在Redis中，自动过期清理
4. **邮件模板**：HTML格式，包含品牌样式和过期时间
5. **忘记密码**：发送重置链接，有效期30分钟

### 邮件服务配置
- **发件邮箱**：需要在 `.env` 文件中配置 `FROM_EMAIL`
- **SMTP服务器**：支持Gmail、SendGrid、阿里云等
- **当前配置**：使用Gmail SMTP（需要应用专用密码）

### 费用说明
- **Gmail免费版**：每天500封邮件
- **Gmail付费版**：无限制
- **SendGrid免费版**：每月100封邮件
- **SendGrid付费版**：$14.95/月起
- **阿里云邮件推送**：¥1/千封起

## ⚙️ 配置说明

### 邮件服务配置
要启用邮件功能，需要在 `.env` 文件中配置：

```env
# Gmail配置示例
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your_email@gmail.com
SMTP_PASSWORD=your_app_specific_password
FROM_EMAIL=your_email@gmail.com
```

### Gmail应用专用密码设置
1. 登录Gmail账户
2. 进入"管理您的Google账户"
3. 选择"安全性" > "两步验证"
4. 启用两步验证
5. 生成"应用专用密码"
6. 将密码填入 `SMTP_PASSWORD`

## 🔍 故障排除

### 常见问题

1. **邮件发送失败**
   - 检查SMTP配置
   - 确认应用专用密码正确
   - 检查网络连接

2. **登录失败**
   - 确认账号密码正确
   - 检查数据库连接
   - 查看后端日志

3. **功能权限问题**
   - 确认用户套餐等级
   - 检查积分余额
   - 验证订阅有效期

### 日志查看
- **后端日志**：终端11中的uvicorn输出
- **前端日志**：浏览器开发者工具Console
- **数据库日志**：后端启动时的数据库连接信息
