# IdeaEden 系统启动指南

## 系统概述
IdeaEden 是一个社交媒体趋势分析工具，包含前端用户界面、后端API服务和管理员面板。

## 前端启动

### 前置条件
- Node.js (推荐版本 18+)
- npm 或 yarn

### 启动步骤
1. 打开终端，进入前端目录：
   ```bash
   cd c:\Users\zhang\Desktop\2\social-trend-analyzer
   ```

2. 安装依赖（首次运行）：
   ```bash
   npm install
   ```

3. 启动开发服务器：
   ```bash
   npm run dev
   ```

4. 访问地址：
   - 用户界面：http://localhost:3001
   - 管理员面板：http://localhost:3001/admin/users

### 环境变量配置
前端环境变量文件：`c:\Users\zhang\Desktop\2\social-trend-analyzer\.env`
```
VITE_API_BASE_URL=http://localhost:8000
VITE_APP_ENV=development
VITE_APP_NAME=IdeaEden
VITE_APP_VERSION=2.1.0
```

## 后端启动

### 前置条件
- Python 3.8+
- pip

### 启动步骤
1. 打开终端，进入后端目录：
   ```bash
   cd c:\Users\zhang\Desktop\2\backend
   ```

2. 安装依赖（首次运行）：
   ```bash
   pip install -r requirements.txt
   ```

3. 启动后端服务：
   ```bash
   python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```

4. 访问地址：
   - API文档：http://localhost:8000/docs
   - API根路径：http://localhost:8000

### 环境变量配置
后端环境变量文件：`c:\Users\zhang\Desktop\2\backend\.env`
- 包含数据库连接、API密钥等敏感信息
- 确保文件存在并配置正确

## 常见问题排查

### 前端启动失败
1. 检查Node.js版本是否符合要求
2. 删除`node_modules`文件夹，重新运行`npm install`
3. 检查端口3001是否被占用

### 后端启动失败
1. 检查Python版本是否符合要求
2. 确保所有依赖包已正确安装
3. 检查端口8000是否被占用
4. 验证环境变量文件配置

### 管理员登录失败
1. 确认后端服务正常运行
2. 检查数据库连接是否正常
3. 验证管理员账户是否已创建
4. 查看浏览器开发者工具的网络请求错误

### 用户注册失败
1. 检查前后端服务连接状态
2. 查看浏览器控制台错误信息
3. 验证邮箱格式和用户名唯一性
4. 检查后端日志中的详细错误信息

## 系统架构

### 技术栈
- **前端**：React + TypeScript + Vite + Tailwind CSS
- **后端**：FastAPI + Python + SQLAlchemy
- **数据库**：SQLite（开发环境）
- **认证**：JWT Token

### 服务端口
- 前端开发服务器：3001
- 后端API服务器：8000
- 数据库：本地SQLite文件

## 开发建议

1. **开发环境**：建议同时启动前端和后端服务
2. **代码修改**：前端支持热重载，后端使用`--reload`参数自动重启
3. **调试工具**：使用浏览器开发者工具和后端API文档进行调试
4. **日志查看**：关注终端输出的错误信息和警告

## 生产部署注意事项

1. 修改环境变量为生产环境配置
2. 使用生产级数据库（PostgreSQL/MySQL）
3. 配置HTTPS和域名
4. 设置适当的CORS策略
5. 启用日志记录和监控
