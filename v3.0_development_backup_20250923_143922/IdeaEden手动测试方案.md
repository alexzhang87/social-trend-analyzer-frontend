# IdeaEden 2.0 手动测试方案

## 📋 测试概述

### 测试目标
- 验证前后端所有功能正常运行
- 确保用户体验流畅
- 验证数据分析功能准确性
- 测试系统性能和稳定性

### 测试环境
- **前端**：React + TypeScript + Vite
- **后端**：FastAPI + Python
- **数据库**：SQLite/PostgreSQL
- **浏览器**：Chrome, Firefox, Safari, Edge

## 🚀 测试前准备

### 1. 环境启动检查
```bash
# 后端启动
cd backend
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 前端启动
cd frontend
npm run dev
```

### 2. 基础连接测试
- [ ] 后端API文档访问：http://localhost:8000/docs
- [ ] 前端页面访问：http://localhost:5173
- [ ] 前后端通信正常
