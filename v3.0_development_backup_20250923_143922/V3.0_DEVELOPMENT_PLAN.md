# IdeaEden V3.0 开发方案 - 智能创业助手

## 🎯 项目愿景

**核心理念**: "一个对话解决所有问题"  
**产品定位**: AI驱动的智能创业助手，通过自然对话帮助创业者验证想法、分析市场、制定策略  
**目标用户**: 创业者、产品经理、投资人、商业分析师  

---

## 🚀 V3.0 核心特性

### 1. 智能对话引擎 (Intelligent Conversation Engine)
```
用户: "我想做一个外卖配送的创业项目"
AI助手: "很有趣的想法！让我帮你全面分析一下。首先，你的目标市场是哪个城市？
        我会从市场规模、竞争态势、用户需求等维度为你分析..."

[自动触发]
├── 市场趋势分析 (Google Trends + Reddit数据)
├── 竞争对手分析 (Product Hunt + 行业数据)
├── 用户需求洞察 (社交媒体情感分析)
├── 商业模式建议 (AI生成 + 案例库)
└── PMF评估 (智能问卷 + 数据验证)
```

### 2. 多专家人格系统 (Multi-Expert Personas)
- **市场分析专家**: 专注趋势分析、市场规模、竞争态势
- **产品策略专家**: 专注产品设计、用户体验、功能规划
- **商业模式专家**: 专注盈利模式、成本结构、收入流
- **增长营销专家**: 专注获客策略、营销渠道、增长黑客
- **投资顾问**: 专注融资策略、估值分析、投资人匹配

### 3. 智能工作流 (Intelligent Workflow)
```
对话开始 → 需求识别 → 专家匹配 → 数据收集 → 深度分析 → 洞察生成 → 行动建议 → 持续跟进
    ↓           ↓          ↓          ↓         ↓         ↓         ↓         ↓
  自然语言    意图理解    专家切换    API调用   AI分析    结果整合   策略制定   进度追踪
```

## 🔧 后端架构设计

### AI编排服务 (新增)
```python
# app/services/ai_orchestration_service.py
class AIOrchestrationService:
    def __init__(self):
        self.intent_classifier = IntentClassifier()
        self.expert_matcher = ExpertMatcher()
        self.conversation_manager = ConversationManager()
        self.analysis_coordinator = AnalysisCoordinator()
    
    async def process_user_message(
        self, 
        user_id: str, 
        message: str, 
        conversation_id: str
    ) -> ConversationResponse:
        # 1. 意图识别
        intent = await self.intent_classifier.classify(message)
        
        # 2. 专家匹配
        expert = await self.expert_matcher.match(intent)
        
        # 3. 上下文管理
        context = await self.conversation_manager.get_context(conversation_id)
        
        # 4. 分析协调
        analysis_results = await self.analysis_coordinator.coordinate(
            intent, message, context
        )
        
        # 5. 响应生成
        response = await self.generate_expert_response(
            expert, analysis_results, context
        )
        
        return response
```

## 📊 数据模型设计

### 新增数据表
```sql
-- 对话会话表
CREATE TABLE conversations (
    id UUID PRIMARY KEY,
    user_id UUID REFERENCES users(id),
    title VARCHAR(255),
    current_expert VARCHAR(50),
    context JSONB,
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);

-- 对话消息表
CREATE TABLE conversation_messages (
    id UUID PRIMARY KEY,
    conversation_id UUID REFERENCES conversations(id),
    role VARCHAR(20), -- 'user' | 'assistant' | 'system'
    content TEXT,
    expert_type VARCHAR(50),
    analysis_results JSONB,
    created_at TIMESTAMP
);

-- 分析任务表
CREATE TABLE analysis_tasks (
    id UUID PRIMARY KEY,
    conversation_id UUID REFERENCES conversations(id),
    task_type VARCHAR(50),
    status VARCHAR(20),
    input_data JSONB,
    output_data JSONB,
    created_at TIMESTAMP,
    completed_at TIMESTAMP
);
```
