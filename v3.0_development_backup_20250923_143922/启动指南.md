# IdeaEden 2.0 启动指南

## 系统概述

IdeaEden 2.0 是一个社交媒体趋势分析平台，包含前端界面、后端API服务和管理员面板。

## 前端启动

### 环境要求
- Node.js 16+ 
- npm 或 yarn

### 启动步骤

1. **进入前端目录**
   ```bash
   cd frontend
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动开发服务器**
   ```bash
   npm run dev
   ```

4. **访问地址**
   - 本地地址：http://localhost:3000/
   - 默认端口：3000

### 前端功能模块
- 仪表板页面 - 数据概览和趋势图表
- 趋势分析 - 社交媒体数据分析
- 用户认证 - 登录注册功能
- 反馈系统 - 用户反馈收集

## 后端启动

### 环境要求
- Python 3.8+
- pip
- PostgreSQL 数据库

### 启动步骤

1. **进入后端目录**
   ```bash
   cd backend
   ```

2. **创建虚拟环境**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate     # Windows
   ```

3. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

4. **配置环境变量**
   - 复制 `.env.example` 为 `.env`
   - 配置数据库连接信息
   - 设置API密钥

5. **初始化数据库**
   ```bash
   python init_db.py
   ```

6. **启动服务**
   ```bash
   python -m app.main
   ```

7. **访问地址**
   - API地址：http://localhost:8000/
   - API文档：http://localhost:8000/docs

### 后端功能模块
- RESTful API 接口
- 数据采集服务
- 趋势分析算法
- 用户管理系统
- 缓存和队列处理

## 完整系统启动

### 使用批处理脚本（Windows）

1. **启动所有服务**
   ```bash
   start_system.bat
   ```

2. **单独启动服务**
   ```bash
   start_backend.bat    # 仅启动后端
   start_frontend.bat   # 仅启动前端
   ```

### 使用Docker（推荐生产环境）

1. **启动完整系统**
   ```bash
   docker-compose up -d
   ```

2. **查看服务状态**
   ```bash
   docker-compose ps
   ```

## 常见问题

### 前端问题
- **端口占用**：修改 `vite.config.ts` 中的端口配置
- **依赖错误**：删除 `node_modules` 重新安装
- **组件缺失**：检查 UI 组件是否完整

### 后端问题
- **数据库连接失败**：检查 `.env` 文件中的数据库配置
- **端口占用**：修改 `app/main.py` 中的端口设置
- **依赖冲突**：使用虚拟环境隔离依赖

### 管理员登录问题
- **账号不存在**：运行 `python init_db.py` 创建默认管理员
- **密码错误**：使用默认密码或重置管理员密码
- **权限不足**：确认账号具有管理员权限

## 开发环境配置

### 环境变量文件

**前端 (.env)**
```
VITE_API_URL=http://localhost:8000
VITE_APP_NAME=IdeaEden
```

**后端 (.env)**
```
DATABASE_URL=postgresql://user:password@localhost/ideaeden
SECRET_KEY=your-secret-key
REDDIT_CLIENT_ID=your-reddit-client-id
REDDIT_CLIENT_SECRET=your-reddit-client-secret
```
