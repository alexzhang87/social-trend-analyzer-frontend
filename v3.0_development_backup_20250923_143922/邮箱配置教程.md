# 邮箱验证服务配置教程

本教程将手把手教您如何配置阿里云邮件推送和Gmail免费版作为验证邮箱发送服务。

---

## 🚀 方案一：阿里云邮件推送（推荐）

### 优势
- ✅ 国内服务，稳定性高
- ✅ 价格便宜：¥1/千封起
- ✅ 免费额度：每月200封
- ✅ 到达率高，不易被拦截
- ✅ 支持批量发送

### 步骤1：开通阿里云邮件推送服务

1. **登录阿里云控制台**
   - 访问：https://www.aliyun.com/
   - 登录您的阿里云账号

2. **开通邮件推送服务**
   - 搜索"邮件推送"
   - 点击"立即开通"
   - 选择"按量付费"模式

3. **创建发信域名**
   - 进入邮件推送控制台
   - 点击"发信域名" > "新建域名"
   - 输入您的域名（如：mail.yourdomain.com）
   - 选择"触发邮件"

### 步骤2：域名验证

1. **添加DNS记录**
   ```
   记录类型：TXT
   主机记录：aliyundm-verification
   记录值：（阿里云提供的验证码）
   ```

2. **添加MX记录**
   ```
   记录类型：MX
   主机记录：mail
   记录值：mxdm.aliyun.com
   优先级：10
   ```

3. **添加SPF记录**
   ```
   记录类型：TXT
   主机记录：mail
   记录值：v=spf1 include:spf.mxdm.aliyun.com ~all
   ```

### 步骤3：创建发信地址

1. **创建发信地址**
   - 点击"发信地址" > "新建发信地址"
   - 邮件地址：noreply@mail.yourdomain.com
   - 回信地址：support@yourdomain.com
   - 发信类型：触发邮件

### 步骤4：获取SMTP配置

1. **获取SMTP信息**
   - 服务器地址：smtpdm.aliyun.com
   - 端口：25 或 80（推荐465加密）
   - 用户名：您创建的发信地址
   - 密码：在控制台设置的SMTP密码

### 步骤5：配置项目

在 `.env` 文件中添加：

```env
# 阿里云邮件推送配置
SMTP_SERVER=smtpdm.aliyun.com
SMTP_PORT=465
SMTP_USERNAME=noreply@mail.yourdomain.com
SMTP_PASSWORD=your_smtp_password
FROM_EMAIL=noreply@mail.yourdomain.com
SMTP_USE_TLS=true
```

## 📧 方案二：Gmail免费版

### 优势
- ✅ 免费额度：每天500封
- ✅ 设置简单
- ✅ 全球通用
- ❌ 可能被国内邮箱拦截
- ❌ 需要科学上网

### 步骤1：启用两步验证

1. **登录Gmail账户**
   - 访问：https://gmail.com
   - 登录您的Gmail账号

2. **进入账户设置**
   - 点击右上角头像
   - 选择"管理您的Google账户"

3. **启用两步验证**
   - 点击左侧"安全性"
   - 找到"两步验证"
   - 点击"开始使用"
   - 按提示完成手机验证

### 步骤2：生成应用专用密码

1. **创建应用专用密码**
   - 在"安全性"页面
   - 找到"应用专用密码"
   - 点击"生成"
   - 选择"邮件"
   - 选择"其他（自定义名称）"
   - 输入："社交趋势分析系统"
   - 点击"生成"

2. **保存密码**
   - 复制生成的16位密码
   - 妥善保存（只显示一次）

### 步骤3：配置项目

在 `.env` 文件中添加：

```env
# Gmail SMTP配置
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your_email@gmail.com
SMTP_PASSWORD=your_16_digit_app_password
FROM_EMAIL=your_email@gmail.com
SMTP_USE_TLS=true
```

## 🧪 测试配置

### 创建测试脚本

创建 `test_email.py` 文件：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

import sys
import os
import asyncio
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart
import smtplib

# 添加项目路径
sys.path.append(os.path.dirname(os.path.abspath(__file__)))

from app.core.config import settings

def test_email_config():
    """
    测试邮件配置
    """
    print("开始测试邮件配置...")
    print(f"SMTP服务器: {settings.SMTP_SERVER}")
    print(f"SMTP端口: {settings.SMTP_PORT}")
    print(f"发件邮箱: {settings.FROM_EMAIL}")
    
    try:
        # 创建邮件
        msg = MIMEMultipart()
        msg['From'] = settings.FROM_EMAIL
        msg['To'] = "test@example.com"  # 替换为您的测试邮箱
        msg['Subject'] = "邮件配置测试"
        
        body = """
        <html>
        <body>
            <h2>邮件配置测试成功！</h2>
            <p>如果您收到这封邮件，说明SMTP配置正确。</p>
            <p>发送时间: {}</p>
        </body>
        </html>
        """.format(datetime.now().strftime("%Y-%m-%d %H:%M:%S"))
        
        msg.attach(MIMEText(body, 'html'))
        
        # 连接SMTP服务器
        if settings.SMTP_PORT == 465:
            server = smtplib.SMTP_SSL(settings.SMTP_SERVER, settings.SMTP_PORT)
        else:
            server = smtplib.SMTP(settings.SMTP_SERVER, settings.SMTP_PORT)
            server.starttls()
        
        server.login(settings.SMTP_USERNAME, settings.SMTP_PASSWORD)
        
        # 发送邮件
        text = msg.as_string()
        server.sendmail(settings.FROM_EMAIL, "test@example.com", text)
        server.quit()
        
        print("✅ 邮件发送成功！")
        return True
        
    except Exception as e:
        print(f"❌ 邮件发送失败: {e}")
        return False

if __name__ == "__main__":
    from datetime import datetime
    test_email_config()
```

### 运行测试

```bash
cd backend
python test_email.py
```

## 🔍 常见问题解决

### 阿里云常见问题

1. **域名验证失败**
   - 检查DNS记录是否正确添加
   - 等待DNS生效（最多24小时）
   - 使用 `nslookup` 验证记录

2. **发送失败**
   - 检查发信地址是否已验证
   - 确认SMTP密码正确
   - 检查账户余额

3. **被拦截**
   - 完善SPF、DKIM记录
   - 避免敏感词汇
   - 控制发送频率

### Gmail常见问题

1. **应用专用密码无效**
   - 确认已启用两步验证
   - 重新生成应用专用密码
   - 检查密码中是否包含空格

2. **连接被拒绝**
   - 检查网络连接
   - 确认端口587可用
   - 尝试使用465端口（SSL）

3. **发送限制**
   - Gmail每天限制500封
   - 避免短时间大量发送
   - 监控发送频率
