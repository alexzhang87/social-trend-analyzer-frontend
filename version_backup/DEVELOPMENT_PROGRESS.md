## 下一步操作指南

### 1. 在Stripe仪表板中创建产品和价格
1. 登录 [Stripe官网](https://stripe.com/) 并进入仪表板
2. 在左侧菜单中点击 "Products"
3. 为每个订阅计划和积分包创建产品：
   - Starter Subscription: $9.99/月
   - Pro Subscription: $29.99/月
   - Small Credits Package: $4.99（一次性）
   - Medium Credits Package: $11.99（一次性）
   - Large Credits Package: $24.99（一次性）
4. 记录每个产品的价格ID

### 2. 更新配置文件中的价格ID
1. 打开 `backend/app/api/payments.py` 文件
2. 找到 `STRIPE_PRICE_IDS` 映射
3. 使用实际的价格ID替换占位符

### 3. 配置Webhook
1. 在Stripe仪表板中，转到 "Developers" > "Webhooks"
2. 点击 "Add endpoint"
3. 设置端点URL为：`https://yourdomain.com/api/v1/payments/webhook`
4. 选择必要的事件类型
5. 获取Webhook签名密钥并添加到环境变量中

### 4. 测试支付流程
1. 启动后端和前端服务
2. 登录账户并尝试购买订阅或积分包
3. 验证支付流程是否正常工作
4. 检查支付成功后用户状态是否正确更新
