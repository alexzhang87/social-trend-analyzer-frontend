## 如何恢复

### 方法一：使用自动恢复脚本（推荐）
1. 双击运行 `restore_backup.bat`
2. 按照提示确认恢复操作
3. 脚本会自动备份当前版本并恢复到此备份版本
4. 按照脚本提示重新安装依赖

### 方法二：手动恢复
如果需要手动回滚到此版本：
1. 停止当前运行的服务
2. 将此备份文件夹中的内容复制回主目录
3. 重新安装依赖和启动服务

## 版本对比
使用 `compare_versions.bat` 脚本可以快速对比当前版本与备份版本的差异，帮助您了解具体的修改内容。
